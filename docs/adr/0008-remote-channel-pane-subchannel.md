# Remote Channel hosts Pane sub-channels; chat-as-input in panes

A Discord text channel represents one Remote (host-level Gateway). Panes are sub-channels under that Remote Channel. Operators register host/IP/token via `/herdr`, create Panes via commands in the Remote Channel, and type freely in a Pane Channel to send input to Herdr. Supersedes Category=Remote / top-level Channel=Pane for operator mental model.
